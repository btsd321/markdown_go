### 单元格级对齐（`<div align="X">`）

> 列对齐用分隔行 `:--- / :---: / ---:` 控制；如需在某个单元格上覆盖列对齐，可写 `<div align="...">`。 GitHub 等富 HTML 渲染器会按 div 显示；纯 GFM 渲染器仅按列显示。

| 默认 | 列居中 | 列右对齐 |
| --- | :---: | ---: |
| 普通 | 单元格强制左对齐 | 普通 |
| <div align="center">普通列里强制居中</div> | 默认列居中 | 右对齐列里强制左对齐 |
| <div align="right">单元格强制右对齐</div> | <div align="right">列居中里强制右对齐</div> | 默认右对齐 |

### 表格交互（手动验证）

 1. 输入 `/table` 或点行首 `+` → 选 `表格` → 网格选择 4×3 → 插入
 2. 光标进入任意单元格 → 表格上方浮出工具栏
 3. 上方插入行 / 下方插入行 / 删除当前行
 4. 左侧插入列 / 右侧插入列 / 删除当前列
 5. 切换本列对齐 L/C/R → 保存后磁盘上 `:--- / :---: / ---:` 正确
 6. 拖动列与列之间的边界 → 列宽变化（暂不参与序列化）
 7. Tab / Shift+Tab 在单元格间跳转；最后一格 Tab → 自动新增一行
 8. 单元格内 Shift+Enter 换行 → 写出后变为 `<br>`，再次打开仍展示为换行
 9. 单元格内输入 `|` → 写出后变为 `\|`，再次打开仍是 `|`
10. 删除整张表格按钮 → 整张表消失
11. 在某个单元格内点对齐按钮（左 / 居中 / 右）→ 保存后该 cell 写出 `<div align="X">…</div>`，再次打开仍展示对齐
12. 同列其他单元格的对齐不受单 cell 对齐影响（除非用 TableToolbar 设置整列）
